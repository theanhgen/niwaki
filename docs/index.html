Grow a forest
with agents.

Niwaki plants a pixel-art tree in your terminal after every AI agent prompt. Watch a forest emerge as you build.

Quick start

  1. 1 bun add -g niwaki
  2. 2 niwaki init
  3. 3 niwaki

How it works

01

Install & init

One global install. niwaki init registers a Stop hook inside Claude Code — no manual steps needed.

02

Build with agents

Every time an AI agent completes a response, a new tree is planted automatically in your forest.

03

Watch it grow

Run the viewer in a separate terminal. Your forest grows in real time, biome by biome, as you ship.

Biomes

Your forest evolves as it grows. The sky, ground, and atmosphere change with every milestone.

0–9 Clearing Sparse, quiet
10–24 Grove Taking root
25–49 Woodland Dense canopy
50–99 Old Growth Deep & warm
100+ Ancient Forest Richest palette
